# Stillroom — Offline Standalone Backup

This folder contains a **100% self-contained offline version** of Stillroom that requires **zero installation, zero Node.js, zero npm, zero internet, and zero local web servers**.

---

## 🛡️ Why this exists
If school or corporate IT restrictions:
- Block running terminal scripts (`.sh` / `.bat`)
- Block installing Node.js / `npm`
- Restrict opening local network ports (`localhost:5173`)
- Block downloads through restrictive school proxies

---

## 🚀 How to use
Simply **double-click** [`index.html`](./index.html) in your file manager (Finder on macOS or Explorer on Windows).

It will open immediately in any browser (Safari, Chrome, Firefox, Edge) as a `file://` URL and has:
- The exact same color palette and calming design
- Working private reflection journaling with feelings tags
- Live generative SVG colour tapestry generator with interactive sliders
- Full community stories feed with topic filters and working reactions
- Therapy session logger with live session counter and Markdown/text export
- Local browser persistence (`localStorage`)
